# Shalvi Technologies website

Polished static site for www.shalvitechnologies.com.

## Share this site

Zip the folder **`SHARE/Shalvi_Technologies_Website`** and send it.

Open **`SHARE/Shalvi_Technologies_Website/index.html`** in a browser, or run:

```bash
python -m http.server 5173
```

then visit http://127.0.0.1:5173/
